game's core assets (CC BY-NC-SA 4.0). It does not limit any right those licences already give you.

2. You may sell, give away or monetise your mod, even if it uses or modifies core assets, provided that:

Code in a mod that imports the game's code is covered by the GPL like any other work based on it: its source must
be published, though the mod may still be sold, and the mod's own assets stay its author's.
