Contravía is an open-world driving game set in a real-size Cuba. Nothing in its island is modelled by hand: the streets, buildings, coasts, rivers and trees are generated from OpenStreetMap, the Copernicus relief and ESA's land cover, by rules that say what each kind of place looks like. The same inputs always give the same island, because every random draw is seeded from an OSM id or a block's centre. The game is also a technical demo for students and a stress test for manifoldx, the engine it runs on.

This guide explains how that island is built, streamed and simulated, from the top down. It is about the ideas rather than the code: each chapter states a problem (how does a street meet a hillside? how is a whole island kept in memory?), shows how the game solves it, gives the sizes and thresholds it uses, and draws the result with the game's own modules. Code appears only where a short call draws a figure, and every such block runs against the package when the guide is built.

The [Quick start](#quick-start) gets the game running from the repository and changes it. The player's side of the game, from installing it to the album, is in the player's manual (*Manual del jugador*), in Spanish.
